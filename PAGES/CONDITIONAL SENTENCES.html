📚 Conditional Sentences

Aprenda a usar as frases condicionais em inglês

📖 O que são Frases Condicionais?

🔹 Estrutura Geral

Uma frase condicional tem duas partes:

  • If clause (condição) - a parte que começa com "if"
  • Main clause (resultado) - o que acontece se a condição for atendida
IF + condição , RESULTADO
If it rains, I will stay home.

🔹 Os 5 Tipos de Condicionais

Zero Conditional ZERO

📌 Fatos gerais, verdades científicas, coisas que sempre acontecem
If + Present Simple , Present Simple
If you heat water, it boils.
If I am late, my boss gets angry.

First Conditional 1ª

📌 Possibilidades reais e prováveis no futuro
If + Present Simple , will + verbo base
If it rains tomorrow, I will stay home.
If you study, you will pass the exam.

Second Conditional 2ª

📌 Situações hipotéticas, improváveis ou imaginárias no presente
If + Past Simple , would + verbo base
If I had a million dollars, I would travel the world.
If I were you, I would accept the job.

* Com o verbo to be, usamos were para todas as pessoas.

Third Conditional 3ª

📌 Situações passadas que não aconteceram (arrependimentos)
If + Past Perfect , would have + Past Participle
If I had studied harder, I would have passed the exam.
If she had left earlier, she wouldn't have missed the train.

Mixed Conditional MISTA

📌 Combinações: passado + presente / presente + passado
If + Past Perfect , would + verbo base (passado → presente)
If + Past Simple , would have + Past Participle (presente → passado)
If I had taken the job, I would be rich now.
If I weren't afraid of flying, I would have traveled more.

🔹 Resumo dos Tipos

Tipo If Clause Main Clause Uso
Zero Present Simple Present Simple Fatos / Verdades
1ª Present Simple will + verbo base Possibilidades reais
2ª Past Simple would + verbo base Hipotéticas (presente)
3ª Past Perfect would have + past participle Hipotéticas (passado)
